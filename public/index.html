叁.skill 文件

一个人，
可以被写进
一页文字里吗?

不是 prompt，是传记。

.skill 用 Markdown 和 YAML 写成，任何文本编辑器都能打开。
它记录的不是"人设"，是一个人真实的边角： 他常说的那句话、对哪件事念念不忘、哪种话题他不愿意谈。

你可以自己改、自己删、自己传给弟弟妹妹。
哪一天你不想要了，一个键就能让它彻底消失。

一份 .skill 的平均长度，大约是 2000 字。
不长，但每一句都是你亲手记下来的。

肆四条守则

我们答应过
自己的几件事。

守则一

完全本地

所有数据、照片、录音、.skill 都存在你手机里。没有服务器，没有云端，没有账号。我们看不到，也不想看到。

守则二

完全开源

MIT License。代码在 GitHub 上。你可以自己编译，也可以自己审计。我们不做黑盒。

守则三

自带钥匙

AI 对话用你自己的 API Key。推荐 DeepSeek，便宜、好用。我们不内置 Key，不收一分钱，不代理任何请求。

守则四

一屏一事

长辈们也可能打开它。按钮够大，文字够清楚。不弹通知，不做广告，不诱导分享。

伍伦理声明

我们知道自己
在触碰一件很重的事。

  • 这不是"复活"。对话生成的内容，来自你记下的那份 .skill，不是真人。它会出错，会跑偏，会说出长辈从未说过的话。请记住这一点。
  • 声音克隆需授权。只能克隆本人在世时明确同意的，或由直系亲属授权的声音。我们不会预置任何名人语音。
  • 不做祭拜仪式。不烧纸钱，不做法事，不涉及任何宗教行为。我们只做记录与对话。
  • 随时可销毁。一键删除某位长辈的全部数据，不留备份、不留缓存、不可恢复。记忆是你的，走或留都由你决定。
