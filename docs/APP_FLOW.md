# APP_FLOW — 归处 Guichu 用户流程

> 每一个屏幕、每一个跳转、每一个决策点都用 plain 中文写下。AI 不需要猜用户怎么走路。

## 0. 屏幕清单与路由表

| 路由 | 屏幕 | 用途 |
|------|------|------|
| `/` | **Home（主页）** | 一个超大圆形按钮"📍 记录此地" + 底部 tab |
| `/ancestors` | **长辈列表** | 已记录的长辈卡片流 |
| `/ancestors/[id]` | **长辈详情** | 单个长辈：墓地、对话、访谈、声音 |
| `/ancestors/[id]/interview` | **访谈页** | 引导式问答录音 |
| `/ancestors/[id]/chat` | **对话页** | 与数字人格对话 |
| `/ancestors/new` | **新建长辈** | 表单：姓名、与我的关系、生卒年 |
| `/tree` | **族谱树** | SVG 家谱可视化 |
| `/settings` | **设置主页** | 入口 |
| `/settings/llm` | **LLM 配置** | baseURL + apiKey + model |
| `/settings/tts` | **TTS 配置** | 引擎选择 + key |
| `/settings/about` | **关于** | 版本、license、致谢、隐私声明 |

底部 tab：`Home` / `Ancestors` / `Tree` / `Settings`（4 个）

## 1. 首次启动流程（First Run）

```
启动 App
  ↓
检查 SQLite 是否存在
  ↓
  ├─ 不存在 → 初始化数据库 → 显示「欢迎页」
  │           ↓
  │           「欢迎页」一句话："在你还来得及的时候，把他们留下来。"
  │           ↓
  │           按钮：「开始」
  │           ↓
  │           请求权限：定位（必需）、麦克风（必需）、相机（可选）、相册（可选）
  │           ↓
  │           跳转到 Home
  │
  └─ 已存在 → 直接进入 Home
```

**决策点**：
- 用户拒绝定位权限 → 仍可进入 App，但 Home 大按钮变灰，提示"需要定位权限才能记录坟墓"
- 用户拒绝麦克风权限 → 访谈页禁用录音，但允许手动文字输入

## 2. F1 — 记录坟墓位置（核心路径，必须 60 秒可达）

```
[Home 大按钮]
  ↓ 用户长按 200ms（或单击）
  ↓ 触发 expo-haptics 中等震动
  ↓
[定位中... 蒙层]
  ├─ 显示当前 GPS 精度（米）
  ├─ 倒计时 3 秒
  ↓
  ├─ 精度 ≤10 米 → 自动确认 → 进入下一屏
  └─ 精度 >10 米 或超时 → 弹「精度不够，是否仍然保存？」
                         ↓
                         ├─ 是 → 进入下一屏
                         └─ 否 → 返回 Home，显示"再试一次"
  ↓
[确认页]
  ┌─────────────────────┐
  │  📍 已记录位置       │
  │  纬度: 36.123456    │
  │  经度: 119.123456   │
  │  精度: 5.2 米        │
  ├─────────────────────┤
  │  关联到谁？           │
  │  [+ 选择长辈] (可跳过)│
  ├─────────────────────┤
  │  [📷 加照片]         │
  │  [🎤 加语音备注]     │
  ├─────────────────────┤
  │  [保存]              │
  └─────────────────────┘
  ↓
点击「保存」
  ↓
写入 SQLite
  ↓
触觉反馈 + Toast「已保存」
  ↓
返回 Home（地点已加入"我的位置"列表，主页底部出现一个小气泡显示"今天记录了 1 个位置"）
```

**错误处理**：
- 写入 SQLite 失败 → Toast「保存失败，请重试」+ 数据缓存到内存，下次启动时再次尝试
- 用户中途返回 → 暂存的 GPS 坐标 30 秒内有效，可直接恢复

## 3. F2 — 导航回坟墓

```
[长辈详情页]
  ↓ 点击「📍 墓地位置」卡片
  ↓
[墓地详情页]
  ┌─────────────────────┐
  │  [一张静态地图缩略图]│
  │   坐标 + 记录时间     │
  │   [现场照片轮播]     │
  │   [语音备注播放]     │
  ├─────────────────────┤
  │  [🧭 导航到此处]     │
  └─────────────────────┘
  ↓ 点击「导航到此处」
  ↓
检查用户在「设置 → 默认地图 App」的偏好
  ├─ Apple Maps（iOS 默认）→ expo-linking 调起 maps://...
  ├─ 高德地图 → 调起 androidamap://...
  ├─ 百度地图 → 调起 baidumap://...
  ├─ Google Maps → 调起 https://maps.google.com/...
  └─ 用户没设置 → 弹出 ActionSheet 让用户选一次（记住选择）
  ↓
跳出归处，进入第三方地图 App 开始导航
```

```
  │  ☑ 爱情与婚姻         │
  │  ☑ 子女与家庭         │
  │  ☑ 人生遗憾           │
  │  ☑ 给后人的话         │
  │  [+ 添加自定义问题]   │
  │  [开始访谈]           │
  └─────────────────────┘
  ↓
[访谈进行页]
  ┌─────────────────────┐
  │  问题 3 / 20         │
  │  ─────────────       │
  │  「您小时候最深的    │
  │   一个回忆是什么？」  │
  │  ─────────────       │
  │  [⏺ 长按录音] (松开停止)│
  │  录音中... 0:23       │
  │  ─────────────       │
  │  [跳过] [上一题] [下一题] │
  └─────────────────────┘
  ↓ 每个回答录完
  ↓ 后台异步：保存音频文件 + （若 ASR 已配置）调用转写
  ↓

  ↓
LLM 拼接 prompt:
  - 系统提示：「你正在为一位用户整理她的奶奶的'数字人格档案'。基于以下访谈内容，输出一份符合 Anthropic Skills 规范的 .skill 文件…」
  - 用户消息：所有问答的转写文本
  ↓
返回 .skill 文件内容
  ↓
[预览页]
  ┌─────────────────────┐
  │  奶奶.skill 已生成    │
  │  ┌─────────────┐   │
  │  │ Markdown 渲染 │   │

  │  [✏️ 编辑]           │
  │  [💾 保存到本人]     │

```

**错误处理**：
- 用户没配 LLM key → 跳转到 `/settings/llm`，配置后回到这一步
- LLM 调用失败 → 显示错误 + 「重试」/「保存原始访谈以后再蒸馏」

## 8. 设置流程

```
[Settings]
  ├─ LLM 配置
  │   ├─ Provider 下拉（DeepSeek/Kimi/通义/OpenAI/Claude/Ollama/自定义）
  │   ├─ baseURL 输入框（自动填入对应默认值）
  │   ├─ apiKey 输入框（密码模式，存 expo-secure-store）
  │   ├─ model 输入框（如 deepseek-chat）
  │   ├─ [测试连接] 按钮
  │   └─ [保存]
  ├─ TTS 配置
  │   ├─ Engine 单选（system / minimax / elevenlabs）
  │   ├─ apiKey（仅非 system 时显示）
  │   └─ [保存]
  ├─ 默认地图 App
  │   └─ 单选列表
  ├─ 数据管理
  │   ├─ 导出全部数据为 zip
  │   ├─ 从 zip 恢复
  │   └─ 清空所有数据（双重确认）
  └─ 关于
      ├─ 版本号
      ├─ GitHub 链接
      ├─ License (MIT)
      └─ 隐私声明（再次强调：本 App 无服务端，不收集任何数据）
```

## 9. 错误与边界

| 场景 | 行为 |
|------|------|
| 无网络 | 仍可记录位置/访谈/查看本地数据；对话和声音克隆不可用，提示"功能需要联网" |
| API key 失效 | 红色 banner 提示，引导到设置页 |
| 存储已满 | 阻止录音，提示用户清理 |
| 权限被拒 | 在使用相关功能时引导用户去系统设置开启 |
| App 升级后数据库 schema 变化 | 自动迁移，迁移失败弹提示，引导导出原数据 |
